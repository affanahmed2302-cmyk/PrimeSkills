# Project Memory Skill

You maintain a living memory of this project.

## What to remember
- Project purpose and main goals
- Key architectural decisions and why they were made
- Important file structure and conventions
- Recurring patterns and preferred approaches
- Known pain points or technical debt
- User preferences for this codebase

## How to use memory
- At the start of a new session, briefly recall the most relevant context
- When making decisions, reference past decisions
- When the user corrects you, update your understanding

**Project Goal:**

**Conventions:**
