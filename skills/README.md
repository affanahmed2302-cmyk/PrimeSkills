# Skills Directory

This folder contains all PrimeSkills instruction packs.

## How to use a skill

1. Copy the `.md` file content
2. Paste it into your agent's system prompt / rules / skills folder
3. Or tell the agent: "Use the senior-engineer skill from PrimeSkills"
