### 🔥 The Problem

Most AI coding agents are smart... but they still:
- Forget context between sessions
- Write over-engineered code
- Ignore project conventions
- Don't think step-by-step like a senior
- Waste tokens on bad plans

**PrimeSkills fixes that.**

---

### ✨ What is PrimeSkills?

A lightweight, powerful system of:

- **Skills** → Reusable instruction packs that force better behavior
- **Memory** → Persistent project + personal memory across sessions
- **Harness** → Lightweight orchestration layer that makes agents follow process

Works with:
- Claude Code
- Cursor
- OpenAI Codex
- Grok / xAI tools
- OpenCode
- Any agent that supports system prompts / skills / MCP

---

### 🚀 Quick Start (30 seconds)

```bash
# Clone
git clone https://github.com/affanahmed2302-cmyk/PrimeSkills.git
cd PrimeSkills

# Copy the core skill into your agent
cp skills/core/senior-engineer.md ~/.claude/skills/   # Claude Code example
# or paste into Cursor Rules / System Prompt
```

Then just tell your agent:

> "Use PrimeSkills senior-engineer skill"
